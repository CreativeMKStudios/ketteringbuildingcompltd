# Kettering Building Company Ltd

Static site for the Kettering builder listed at 34 St Oswalds Close, NN15 5HZ.

Public facts are taken from Companies House company 15135190, the Google listing, and the Rated People profile. The limited company was dissolved on 18 February 2025. That status is on the site. Review text is quoted as published, including the 1-star review. The Google listing had no photo gallery to copy, so the site does not use stand-in pictures of other people’s houses.

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```

Set `site` in `astro.config.mjs` to the real domain before you publish. Canonical links, the sitemap, and `public/robots.txt` use `https://ketteringbuildingcompanyltd.co.uk` until you change them.

No page on this site can guarantee a Google ranking.
